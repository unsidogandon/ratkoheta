# Ратко Хета (Rheta)

**1391 модуль** модулей собранные с FHeta (на момент создания модуля было именно столько).

## Установка модуля поиска

```.loadmod https://raw.githubusercontent.com/unsidogandon/ratkoheta/main/Rheta.py```

Команды:

- ``.rheta <запрос>`` — поиск модулей
- ``.rupdate`` — обновить модуль до последней версии из репо

Источник коллекции: FHeta (@NFHeta_Updates)
